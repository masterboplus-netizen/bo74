# 🎨 UI_SPEC — Визуальные правила (bo-web)

> **ВНИМАНИЕ ДЛЯ ИИ:** Перед изменением любого UI-элемента, проверь этот файл. Не меняй размеры/цвета/поведение без явного указания.

## 1. Цветовая схема (CSS Variables)
- `--accent: #007aff` (синий, кнопки, выделение)
- `--bg: #0d1117` (основной фон)
- `--bg2: #161b22` (карточки, капсулы)
- `--bg3: #30363d` (рамки, инпуты)
- `--fg: #c9d1d9` (основной текст)
- `--fg-dim: #8b949e` (второстепенный текст)

## 2. Капсула (нижняя панель)
- Ширина: `260px` (фиксированная, `flex-shrink: 0`)
- Отступы: `4px`
- Радиус: `24px`
- Фон: `var(--bg2)`, рамка: `1px solid var(--bg3)`
- **Запрет:** не менять ширину (иначе прыгает).

## 3. Шторка выделения (selection sheet)
- Позиция: `bottom: 0`, `z-index: 10010`
- Перекрывает нижнюю навигацию.
- `box-sizing: border-box`, `padding: 15px 15px 35px 15px`.
- **Запрет:** не уменьшать `z-index` (иначе навигация перекроет).

## 4. Режим выделения фото
- Сетка остается `4 колонки`.
- Выделенное фото: `transform: scale(0.85)`.
- Галочка: синий фон (`#007aff`), белая обводка, SVG-галочка.
- **Запрет:** не менять количество колонок.

## 5. Карточка объекта (модалка)
- `max-width: 500px`, `margin: 0 auto`, `padding: 20px`, `border-radius: 16px`.
- Все инпуты: `box-sizing: border-box`.
- **Запрет:** не убирать `margin: 0 auto` (иначе упирается в край).

## 6. Карточка редактирования объекта
- Поля: Название, Город, Улица, Дом, Корпус, Подъезд, Этаж, Квартира, Ключ.
- Все инпуты: `width: 100%`, `padding: 10px`, `box-sizing: border-box`.
- **Запрет:** не добавлять лишние разделители (линии) между полями.
