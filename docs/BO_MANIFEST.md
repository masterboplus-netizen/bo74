## 1. ЧТО ТАКОЕ «БО»

«Бо» — цифровая экосистема для строительной компании. Telegram-бот + SQLite + Python 3.13.

Задача: превратить ремонт из «хаоса в голове прораба» в управляемый процесс. Единый цифровой двойник объекта: замеры, электрика, сантехника, сметы, задачи, финансы, CRM.

Принцип: максимум контекста, минимум действий от человека.

## 3. КЛЮЧЕВАЯ АРХИТЕКТУРА

### Объект → Комната → Сессия → Замеры
Объект (квартира/офис/дом)
  └─ Комната (помещение)
       └─ Сессия замеров (первичная, под мебель, финальная)
            └─ Замеры стен, проёмов, ниш, коммуникаций

### ЭОМ (электрика)
Объект → Щит → Группа → Точка
- Щит: ВРУ, этажный, квартирный, уличный. Иерархия — parent_panel_id.
- Группа: привязана к щиту. Один автомат на группу.
- Точка: розетка/выключатель/светильник (room_comms).
- Трасса: кабель щит → точка. Авто-расчёт метража.
- Компоненты щита: автоматы, УЗО, дифавтоматы, шины, клеммы.
- Ручные компоненты: is_manual=1 (не затираются автокомплектацией).

### Сантехника
Объект → Коллектор → Точка
- Коллектор = аналог щита (plumbing_panels).
- Точка = смеситель/унитаз/полотенцесушитель.
- Привязка точки к коллектору: plumbing_panel_points (many-to-many).
- Трассы: вода ХВС/ГВС, канализация.

### PDF-экспорт
core/export/pdf_export.py (reportlab):
- export_panel_spec_pdf(panel_id) — спецификация щита
- export_object_elec_pdf(object_id) — ЭОМ объекта
- export_plumbing_estimate_pdf(object_id) — смета сантехники

## 7. ПРАВИЛА РАБОТЫ

### Формат работы
- Мобила, Shell через Replit, VPN, скрины до 40 строк
- Код смотрю через sed / grep / cat
- Правки через sed -i, python3 -c (одной строкой), printf + tmp-файл
- Один патч → один py_compile → один скрин
- Перезапуск: bash start_all.sh
- Лог: tail -30 bot_start.log
- Если 30 минут не сдвинулись — стоп, откат, читаем STATE.md
