## Уровень 2: Дома с двойным светом и лестницами

### Проблема
Сейчас: комната = 4 стены, одна высота.
Для дома с двойным светом (280→680 см) — не работает.
Лестница — не стена, отдельный объект.

### Решение (предварительное)
1. Комната имеет:
   - height_wall (высота стен, обычно 280 см)
   - height_ceiling (высота потолка, обычно = height_wall, для двойного света 680 см)
2. Стены рисуются до height_wall.
3. Пространство height_wall – height_ceiling — «двойной свет».
4. Лестница — объект в комнате (как мебель).
   - привязка к стене + offset
   - высота ступеней
   - направление (вверх/вниз)

### UI
1. Выбор типа комнаты: «Обычная» / «Двойной свет» / «С лестницей».
2. Если «Двойной свет» — спросить height_ceiling.
3. Если «С лестницей» — спросить привязку лестницы.
