## ПРИМЕР

Фича:
Экспорт комнаты в DXF.

Зачем:
Дизайнеры получают 2D-контур для AutoCAD/SketchUp.

Как работает:
1. Пользователь жмёт «📤 Экспорт» в карточке комнаты.
2. Выбирает DXF.
3. Бот берёт модель из core/model_3d.
4. Генерирует .dxf через ezdxf.
5. Отправляет файл в чат.

Где:
- core/export/dxf_export.py (новое)
- interfaces/telegram/export.py (новое)
- core/spec.py — добавить меню экспорта

Ссылки:
https://raw.githubusercontent.com/masterboplus-netizen/bo74/main/core/measures.py
