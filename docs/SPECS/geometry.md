# SPECS/geometry.md — Модуль геометрии

> Спецификация модуля `core/geometry.py`

---

## 1. НАЗНАЧЕНИЕ

Считает координаты стен, проверяет замыкание контура, конвертирует локальные смещения в 3D-координаты. Основа для экспорта в CAD/BIM.

---

## 2. СИСТЕМА КООРДИНАТ

- Начало — левый нижний угол у двери (0, 0, 0).
- X — вдоль стены «напротив» (стена 1), вправо.
- Y — вдоль стены «слева» (стена 2), вверх.
- Z — высота (от пола).
- Единицы — СМ (при экспорте → ММ).

---

## 3. ФУНКЦИИ

### calc_wall_coords(walls_ordered)
Возвращает список стен с координатами:
[
  {'wall_pos': 'напротив', 'start': (0, 0), 'end': (304, 0), 'length': 304, 'angle_value': 90},
  {'wall_pos': 'слева', 'start': (304, 0), 'end': (304, 250), ...},
  ...
]

Логика:
1. Стена 1 начинается в (0, 0), заканчивается в (L1, 0).
2. Стена 2 начинается в конце стены 1.
3. Угол поворота = (180 − angle_value). Накапливаем.
4. Если angle_value = 90 — прямой угол.

### check_closure(walls)
Возвращает:
- closed: bool
- gap_cm: float
- gap_percent: float

Логика:
1. Берём конец последней стены.
2. Считаем расстояние до начала первой.
3. gap_percent = gap_cm / sum_lengths × 100.
4. Если ≤ 5% — closed = True.

### wall_offset_to_world(wall, offset_x, height)
Возвращает (world_x, world_y, world_z).

Логика:
1. Знаем start и end стены.
2. offset_x — от левого угла стены.
3. height — от пола.
4. Проецируем точку на плоскость стены в 3D.

### calc_corner_coords(walls_ordered)
Возвращает список углов с координатами.

### get_wall_direction(wall)
Возвращает угол направления стены в градусах (0 — вправо, 90 — вверх).

---

## 4. ИНТЕГРАЦИЯ С model_3d.py

geometry.py даёт геометрию.
model_3d.py собирает всё вместе (стены + проёмы + ниши + комм) в единую модель.

---

## 5. ПРАВИЛА

1. Все расчёты — в СМ.
2. При экспорте — конвертация в ММ.
3. Замыкание — критично. Если > 5% — предупреждать.
4. Один источник правды — контур из walls_ordered.
5. Координаты стен — сохранять в room_measures (start_x, start_y, end_x, end_y).
