# SPECS/sessions.md — Модуль сессий замеров

> Спецификация модуля `core/sessions.py`

---

## 1. НАЗНАЧЕНИЕ

Один объект — много версий замеров. Каждая версия — отдельная сессия с датой, типом, автором.

---

## 2. ТИПЫ СЕССИЙ

| Код | Название | Когда |
|-----|----------|-------|
| initial | Первичный (черновой) | До работ |
| after_rough | После черновой | После стяжки/штукатурки |
| furniture | Под мебель | Перед заказом мебели |
| tiling | Под плитку | Перед укладкой |
| mirror | Под зеркала | Перед заказом |
| electric | Под электрику | Перед финишной |
| plumbing | Под сантехнику | Перед установкой |
| final | Финальный | Перед сдачей |
| custom | Свой | По необходимости |

---

## 3. ФУНКЦИИ

### create_session(room_id, session_type, label=None, created_by=None)
Создаёт новую сессию.
Возвращает session_id.
Предыдущие сессии is_active=0.

### get_active_session(room_id)
Возвращает актуальную сессию или None.

### list_sessions(room_id)
Все сессии комнаты (по дате DESC).

### get_session(session_id)
Одна сессия.

### delete_session(session_id)
Удаляет сессию + все связанные замеры, проёмы, ниши, коммуникации.

### set_active_session(session_id)
Делает сессию активной.

---

## 4. СВЯЗИ

Все замеры (room_measures, openings, wall_niches, room_comms) привязаны к session_id.

При запросе комнаты — по умолчанию берём активную сессию.

Можно переключиться на другую — для отчётов, экспорта, смет.

---

## 5. ПРАВИЛА

1. У комнаты всегда есть одна активная сессия (initial).
2. Новая сессия деактивирует предыдущую.
3. Удаление сессии — каскадное.
4. Все UI работают с активной сессией.
5. Экспорт — может указывать session_id явно.
