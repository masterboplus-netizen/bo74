# Зоны обслуживания и точные габариты

## Проблема

На объектах часто возникают конфликты:
- Стиралка не влезает в пенал (реальный размер больше каталожного)
- Нельзя выдвинуть стиралку (полотенцесушитель мешает)
- Не дотягивается кабель/шланг
- Нельзя снять объект (другой объект блокирует)

## Решение — 4 слоя данных

### 1. Точные габариты

| Тип | Поле | Что это |
|-----|------|---------|
| Каталог | dim_catalog_* | Что пишут в магазине |
| Факт | dim_actual_* | Реальный размер (с выпираниями) |
| Упаковка | dim_shipping_* | Для доставки |
| Зазор | clearance_* | Сколько нужно для встраивания |

### 2. Выпирания

| Поле | Что |
|------|-----|
| dim_front_protrusion | Люк стиралки, ручка холодильника |
| dim_top_protrusion | Консоль управления |
| dim_side_protrusion | Боковые ручки/шланги |

### 3. Зоны обслуживания

| Поле | Что |
|------|-----|
| service_zone_front | Сколько надо спереди для выдвижения |
| service_zone_side | Сбоку для доступа |
| service_zone_top | Сверху для вентиляции |

### 4. Демонтаж

| Поле | Что |
|------|-----|
| needs_removal | Требует ли снятия |
| blocking_objects | JSON: список id, которые блокирует |

## Логика проверок

### check_object_fit
- dim_actual + clearance должны влезать в нишу
- dim_front_protrusion не мешает открытию
- dim_top_protrusion не упирается в потолок

### check_service_access
- В зоне service_zone_front не должно быть препятствий
- В зоне service_zone_side не должно быть препятствий
- В зоне service_zone_top не должно быть препятствий

### check_removal_order
- Граф блокировок: A блокирует B, B блокирует A -> цикл
- Строим порядок снятия (топологическая сортировка)
- Если цикл -> ошибка

### check_cable_hose
- Расстояние от розетки до объекта <= cable_length
- Расстояние от воды/слива <= hose_length

## Пример

Стиралка в пенале. Проверка:

1. Влезает ли по факту? (dim_actual + зазор)
2. Люк выпирает? (dim_front_protrusion)
3. Консоль выпирает? (dim_top_protrusion)
4. Розетка в зоне Y=0.85-1.10?
5. Вода в зоне Y=0.6-0.9?
6. Слив в зоне Y=0.6-0.9?
7. Кабель дотягивается? (cable_length)
8. Шланг дотягивается? (hose_length)
9. Зона спереди свободна? (service_zone_front)
10. Полотенцесушитель не блокирует?

Если что-то не так -> конфликт с описанием.
