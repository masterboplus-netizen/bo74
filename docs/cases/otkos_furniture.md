# Кейс: откосы после мебели

## Объект
Остров (Терехово)

## Ситуация
Собрали мебель. Дверные откосы ещё не готовы.
Дизайнер сомневалась: угловые накладки / шпаклевка.

## Проблема
Решение затянулось. Пришлось шпаклевать откосы
ПОСЛЕ установки зеркала и мебели.

Трудности:
- Мало места (мебель мешает)
- На стене уже стеклохолст и финишная шпаклёвка
- Риск испортить финиш

## Решение
Шпаклевали в неудобной позе. Возможно.

## Результат
Работа выполнена, но с трудом. Могло быть проще.

## Выводы для Бо
1. Последовательность: откосы -> финиш -> мебель -> зеркала.
2. Если решение открыто — блокировать следующие задачи.
3. Финишные зоны — запрет работ после финиша.
4. Предупреждать: «сейчас легко, потом сложно».
5. Сохранять кейс в базу знаний.
