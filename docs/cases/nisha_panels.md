# Кейс: панели в кривой нише

## Объект
Остров (Терехово)

## Ситуация
Дизайнер купила 5 жёстких панелей. Заранее спросила высоту и ширину ниши.
Замерщик замерил ширину в одном месте — 110 см.

## Проблема
Фактическая ширина ниши:
- Внизу: 110.5 см
- Вверху: 113 см
Разница: 2.5 см (ниша со смещением, не параллельная)

Панели жёсткие — не согнутся. Сплошная наклейка даст зазор клином.

## Решение
3 панели — по центру ниши, с симметричными зазорами по краям.
1 панель — в коридоре.
1 панель — у ТВ/тумбы.

## Результат
Визуально — лучше, чем сплошная наклейка. Симметрия скрывает кривизну.

## Выводы для Бо
1. Замерщик должен мерить в 3 точках: верх, центр, низ.
2. Бо должен предупреждать: «панель жёсткая — зазор неизбежен».
3. Бо может предложить: «монтировать по центру с зазорами».
4. Сохранять кейсы — на будущее другим клиентам.
