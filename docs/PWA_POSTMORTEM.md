## ГЛАВНЫЕ ОШИБКИ (НЕ ПОВТОРЯТЬ)
1. Replit не подходит для хостинга PWA. Он усыпляет контейнеры (ошибка 502).
2. Chrome на Android кэширует ID приложения. Если поменять домен (даже на GitHub Pages или Surge), он все равно пишет «уже установлено», если в манифесте остался старый `id`.
3. Шаблоны Jinja2 нельзя просто так заливать на статический хостинг. Нужно либо подставлять данные через Python (рендерить в HTML), либо использовать JS для запросов к API.

## РЕШЕНИЕ НА БУДУЩЕЕ
1. **Не использовать PWA.** Для мобильного приложения писать на Flutter или React Native.
2. Для веба использовать нормальный хостинг (Render, Railway), а не Replit и не GitHub Pages (если нужен Python).
3. Если делать PWA — только с полным интерфейсом, а не с пустой заглушкой. Chrome не ставит пустые страницы.
