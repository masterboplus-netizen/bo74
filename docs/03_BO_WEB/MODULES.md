# BO WEB — Модульная архитектура

> **Дата:** 2026-10-31
> **Статус:** Активная разработка. Переход на ES6-модули завершен.

## СТРУКТУРА ФАЙЛОВ

bo-web/
├── index.html              # Только разметка (шапка, меню, контейнеры)
├── manifest.json           # PWA-манифест
├── sw.js                   # Service Worker (кеширование)
├── js/
│   ├── main.js             # Точка входа, роутинг, window-функции
│   ├── api/
│   │   ├── supabase.js     # Клиент Supabase (db)
│   │   └── objects.js      # Запросы к таблице objects
│   ├── screens/
│   │   ├── objects.js      # Отрисовка списка объектов
│   │   ├── objectDetail.js # Карточка объекта
│   │   └── objectEdit.js   # Форма редактирования
│   └── modals/
│       └── add_menu.js     # Всплывающее меню + и форма создания

## ПРАВИЛА РАБОТЫ С МОДУЛЯМИ

1. Никаких god objects. Каждый файл отвечает за одну задачу.
2. API отдельно от UI. Запросы к Supabase живут в js/api/, отрисовка — в js/screens/.
3. window-функции. Все функции, которые вызываются из index.html (onclick), должны быть явно привязаны к window в js/main.js.
4. Не переписывать index.html без необходимости. Он содержит только разметку и подключение js/main.js.

## ГЛАВНЫЕ ОГРАНИЧЕНИЯ

1. Не трогать sw.js. Текущая версия (v113) работает.
2. Не создавать app2.js заново. Он удален.
3. Не использовать import re (регулярки) в Python-скриптах для правки кода.
