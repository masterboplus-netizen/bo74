# BO WEB — Архитектура веб-версии

> **Дата:** 2026-10-25
> **Проект:** Бо Веб (MVP)

## 1. ГЛАВНЫЙ ПРИНЦИП
Веб-версия — это отдельный интерфейс (пульт управления), который общается с тем же самым Ядром (core/), что и Telegram-бот. Ядро ничего не знает о том, что его вызывают через браузер.

## 2. СЛОИ ВЕБ-ВЕРСИИ

1. **Frontend (Клиент):** HTML/CSS/JS (в папке bo-web). Отображает данные.
2. **Backend (Сервер):** Python (web_app.py или interfaces/api/main.py).
3. **Слой бизнес-логики:** core/rooms_logic/ (чистые функции без Telegram).
4. **База данных:** SQLite (bo72.db).

## 3. ОСОБЕННОСТИ REEPILIT (ВАЖНО)

**Проблема:** Replit не поддерживает стандартный запуск FastAPI (uvicorn) в режиме Preview. Он выдает ошибку или не открывает порт.

**Решение (костыль):**
- Вместо uvicorn используется встроенный в Python socketserver (web_app.py).
- Сайт работает на порту 8080.
- Telegram-бот работает в фоне (через Replit Workflows).
- Дашборд (старый web_dashboard.py) временно отключен, чтобы не конфликтовать за порт 8080.

**Правило:** Если Replit не запускает сайт — проверяй настройки socketserver, а не FastAPI.

## 4. API РОУТЫ (Текущие)

- GET / — Главная страница (веб-панель).
- GET /api/objects — Список объектов (JSON).
- GET /api/rooms/{id}/walls — Данные о стенах комнаты.
- GET /api/rooms/{id}/report — Полный отчет по комнате.

## 5. ПРАВИЛА РАЗРАБОТКИ ВЕБА

1. **Не дублировать логику:** Если нужно посчитать смету, вызывай функцию из core/room_estimate.py, а не пиши новую в web_app.py.
2. **JSON:** API должно возвращать чистый JSON (словари), а Frontend сам решает, как это отрисовать.
3. **CORS:** Настроен для доступа с GitHub Pages (домен masterbo.work.gd).
