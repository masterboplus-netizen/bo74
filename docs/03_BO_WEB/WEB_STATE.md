# BO WEB — Журнал разработки и архитектура

> **Проект:** Веб-версия экосистемы «Бо» (отдельно от Telegram-бота).
> **Статус:** Фаза 1 (MVP) — ~45%. Фронтенд на моках (localStorage), реальный API пока не подключён.

## 1. СЕССИЯ 24 — ПОЧИНКА ФРОНТЕНДА (29.10.2026)

### Что сделано (bo-web):
1. **Свайп нижнего меню:** переписан обработчик в `index.html`. Теперь меню корректно открывается и закрывается (удалён мешающий `#swipe-zone`, добавлен `touch-action: none`, защита от потери `touchend`).
2. **Безопасность (XSS):** в `app2.js` добавлена функция `escapeHtml()` для экранирования имён объектов при выводе в DOM.
3. **Баг кликов:** исправлен вызов `onclick` для карточек объектов (теперь передается `id` вместо `JSON.stringify`, который ломался на кавычках в названиях).
4. **Подсветка меню:** в HTML добавлены `id="nav-main"` и `id="nav-objects"`, чтобы заработала функция `setNavActive()`.
5. **Синхронизация версий:** версия везде приведена к `7.1` (включая `manifest.json`).
6. **Очистка:** `localStorage.clear()` заменен на точечное `localStorage.removeItem('bo_objects')`.

## 2. СЕССИЯ 23 — СТАРТ API (20.10.2026)
1. Создан слой бизнес-логики `core/rooms_logic/` (walls, comm, openings, elec, floors, reports).
2. Создан `interfaces/api/` (FastAPI, порт 8080): main.py — 3 роута (/, /api/rooms/{id}/walls, /api/rooms/{id}/report).
3. `.replit` — добавлен воркфлоу FastAPI.

**Проблема Replit:** FastAPI (uvicorn) не работает в Preview. Сайт работает на `web_app.py` (socketserver).

## 3. СЕССИЯ 21 — API ДЛЯ ОБЪЕКТОВ И ДОМЕН (21.10.2026)
- **API:** Добавлен роут `/api/objects` (отдает данные из bo72.db).
- **CORS:** Настроен для доступа с GitHub Pages.
- **Веб (bo-web):** Создан интерфейс (главное меню, список объектов на моках).

## 4. ПОПЫТКА НАСТРОЙКИ ДОМЕНА (Ошибка)
- **Домен:** masterbo.work.gd (freedomain.one) — не привязался.
- **Причина:** `NET::ERR_CERT_COMMON_NAME_INVALID` + 404 от GitHub Pages.
- **Решение:** Отложено. Используем стандартный адрес GitHub Pages.
