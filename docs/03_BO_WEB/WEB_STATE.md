## 3. ПОПЫТКА НАСТРОЙКИ ДОМЕНА (Ошибка)
- **Домен:** Настроен masterbo.work.gd (freedomain.one).
- **DNS:** A-записи GitHub (185.199.x.x) прописаны.
- **GitHub Pages:** Статус built, cname masterbo.work.gd.
- **Ошибка:** NET::ERR_CERT_COMMON_NAME_INVALID (Неверный сертификат).
- **Причина 404:** GitHub Pages отдает 404 (There isn't a GitHub Pages site here).
- **Вывод:** Бесплатные домены третьего уровня (типа work.gd) часто несовместимы с автоматическим SSL от GitHub Pages.
- **Решение:**
  1. Отложить привязку домена.
  2. Использовать стандартный адрес GitHub Pages.
  3. Проверить наличие файла CNAME в корне папки bo-web.
