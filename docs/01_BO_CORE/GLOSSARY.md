# GLOSSARY.md — Глоссарий Бо

> Все термины, которые используются в проекте.

---

## ОБЩИЕ

**Бо** — цифровая экосистема для строительной компании.

**Экосистема** — все компоненты: бот, веб, мобильное, интеграции, экономика, аналитика.

**Ядро (core/)** — бизнес-логика, независимая от интерфейсов.

**Интерфейс** — способ доступа: Telegram, веб, мобильное.

---

## ОБЪЕКТЫ

**Объект** — конкретное место работ (квартира, офис, дом).

**Тип объекта** — bare_walls / ready_repair / cosmetic / frequent_works / designer / commercial.

**Комната** — помещение внутри объекта.

**Сессия замеров** — одна версия замеров комнаты (initial, furniture, final).

**Этап** — фаза ремонта (demolition, rough, comms, plaster, screed, finish, finish_work, handover).

**Вид работ** — конкретная работа (штукатурка, покраска, плитка).

---

## ЗАМЕРЫ

**Замер** — одно измерение (длина стены, высота потолка).

**Проём** — отверстие в стене (окно, дверь, вентиляция).

**Ниша** — углубление в стене.

**Wavy** — стена с разной высотой в разных точках.

**Rounded** — стена со скруглённым углом.

**Hidden** — скрытые коммуникации в стене.

**Коммуникация** — труба, провод, розетка, выключатель, щит.

**Обход стен** — процесс замера 4 стен комнаты по кругу.

**Черновик (wall_draft)** — промежуточное состояние обхода стен.

**Контур** — замкнутая линия стен комнаты.

**Замыкание** — совпадение начала и конца контура.

**Gap** — расхождение замыкания в %.

---

## ГЕОМЕТРИЯ

**Локальная система координат** — начало у двери, X вправо, Y вверх, Z высота.

**World-координаты** — 3D-координаты для экспорта (world_x, world_y, world_z).

**calc_wall_coords** — расчёт координат стен по длинам и углам.

**check_closure** — проверка замыкания контура.

**wall_offset_to_world** — конвертация локального смещения в 3D.

---

## ЭКОНОМИКА

**Смета** — документ с расчётом стоимости.

**Маржа** — разница между доходом и расходом в %.

**Рентабельность** — прибыль / выручка × 100%.

**P&L** — Profit and Loss (отчёт о прибылях и убытках).

**KPI** — Key Performance Indicator.

**Себестоимость** — расходы на материалы + работы.

**FIFO/LIFO** — методы списания себестоимости.

---

## ТЕХНИЧЕСКИЕ

**RBAC** — Role-Based Access Control (роли и права).

**DXF** — Drawing Exchange Format (для CAD).

**IFC** — Industry Foundation Classes (для BIM).

**BIM** — Building Information Modeling.

**CAD** — Computer-Aided Design.

**OCR** — Optical Character Recognition.

**Whisper** — модель распознавания речи.

**SQLite** — база данных (bo72.db).

**WAL** — Write-Ahead Logging (режим SQLite).

**Async** — асинхронный код (async/await).

**Callback** — нажатие кнопки в Telegram.

**Handler** — обработчик (команд, callback'ов).

**Waiting_for** — флаг, что бот ждёт ввода.

**user_data** — временное хранилище состояния.

---

## РОЛИ

**admin** — администратор. Всё.

**prorab** — прораб. Объекты, задачи, финансы, CRM.

**designer** — дизайнер. Замеры, экспорт, отчёты.

**master** — мастер. Задачи, объекты.

**client** — заказчик. Свои объекты, фото, сметы.

**supplier** — поставщик. Заказы, материалы.

**guest** — гость. Минимум.

**JSON** — универсальный формат.

**IFC** — для Revit, BIM.

**PDF** — для печати.

**CSV** — для Excel.
