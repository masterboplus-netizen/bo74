# Инструменты и методы замеров

## Для чего этот документ
Инструкция для замерщика + ТЗ для модуля замеров в Бо.

## Инструменты — минимум

| Инструмент | Зачем | Обязателен |
|-----------|-------|-----------|
| Рулетка 5-10 м | Длины, проёмы | ✅ |
| Лазерный дальномер | Быстро, точно | ⚠️ желательно |
| Уровень (пузырьковый) | Вертикаль, горизонт | ✅ |
| Отвес | Вертикаль стен | ✅ |
| Угольник | Прямые углы | ✅ |

## Инструменты — профессионально

| Инструмент | Зачем |
|-----------|-------|
| Лазерный нивелир (3 плоскости) | Стены/пол/потолок сразу |
| Угломер | Точные углы |
| Дальномер с Bluetooth | Данные в телефон |
| Тепловизор | Скрытые коммуникации |

## Проверка лазера перед выездом

1. Поставить на ровную поверхность
2. Направить на стену (вертикаль)
3. Проверить: линия = вертикаль? Если нет — калибровка
4. Или: на потолок — линия прямая?
5. Если отклонение > 1 мм/м — лазер не готов

## Что должен уметь замерщик

### 1. Длина стены
- Рулеткой — от угла до угла (2-3 замера, взять среднее)
- Дальномером — быстро, в одну точку
- Если стена длиннее рулетки — замер по частям + сложить

### 2. Углы (если не 90°)
- **Метод 60-80-100 (рулетка):** от угла отмеряем 60 см по одной стене и 80 см по другой, замеряем диагональ между точками. Идеал = 100 см.
- **Метод 100-100 (рулетка):** по 100 см по обеим стенам, замеряем расстояние. Идеал = 141 см.
- **Угломер:** точнее, сразу в градусах

### 3. Наклон стены (вертикаль)
- **Отвес:** сверху вниз, замер отклонения низа от верха
- **Уровень:** приложить, посмотреть зазор сверху/снизу
- **Дальномер:** замер на одной высоте в 3 точках (низ/центр/верх)

### 4. Наклон пола (горизонт)
- **Уровень:** положить, посмотреть зазор
- **Лазерный нивелир:** построить горизонталь, замер отклонения в углах

### 5. Проверка лазера перед выездом
- Лазерный нивелир — на ровную стену (проверенный угол), проверить — совпадает ли линия с вертикалью
- Или — на потолок/пол, посмотреть — прямая линия
- Если отклонение > 1 мм/м — калибровка

## Формат данных, которые Бо принимает

### Единицы измерения
- **Длины, высоты, ширины** — в метрах (м), с точностью до 3 знаков (мм)
- **Углы** — в градусах (°), с точностью до 0.1°
- **Ниши** — в метрах (м) — в UI сейчас написано "см", надо привести к метрам
- **Площади** — вычисляются автоматически (м²)

### Ввод в боте
- Юзер вводит число: `2.8` или `2,8` (запятая заменяется на точку)
- Если ошибка — Бо просит: "Нужно число. Например: 2.8"

### Хранение в БД (room_measures)
| Поле | Что | Тип |
|------|-----|-----|
| room_id | Комната | int |
| category | wall/floor/ceiling/window/door | str |
| label | "Стена слева" | str |
| length | Длина | float (м) |
| width | Ширина | float (м) |
| height | Высота | float (м) |
| depth | Глубина | float (м) |
| wall_pos | напротив/слева/справа/у входа | str |
| angle_value | Угол | float (°) |
| angle_method | 60/100/deg | str |
| measured_bottom | Замер внизу | float (м) |
| measured_middle | Замер по центру | float (м) |
| measured_top | Замер вверху | float (м) |
| is_wavy | Разная по высоте (0/1) | int |
| has_rounded | Закругление (0/1) | int |
| rounded_corner | niche / rounded | str |

### Что Бо строит из этих данных
1. **2D-контур комнаты** — соединение стен по углам
2. **3D-модель** — выдавливание контура по высоте потолка
3. **Проверки** — влезает ли мебель, дотягивается ли кабель

### Открытые вопросы

- [ ] Добавить поле `measure_method` (чем замерял: рулетка/лазер/угломер)

## Список вопросов Бо замерщику

### Порядок (сверху вниз, ничего не пропускаем)

**Шаг 0. Подготовка**
- Какой объект? (выбор из списка)
- Какая комната? (выбор или новая)

**Шаг 1. Тип помещения**
- Черновая / Чистовая / Промежуточная?
- От чего считаем замеры? (стяжка / финиш / стены без отделки)

**Шаг 2. Высота потолка**
- Одна на комнату, замер в 3 точках (низ/центр/верх)
- Если разная — отметить отклонение

**Шаг 3. Обход стен по часовой стрелке от двери**
Для каждой стены:
1. **Позиция:** напротив / слева / справа / у входа / дальняя?
2. **Длина:** сколько метров?
3. **Угол:** 90° или есть отклонение?
   - Если отклонение — метод (60-80-100 / 100-100 / угломер)
4. **Плоскость:** ровная или кривая?
   - Если кривая — замер в 3 точках (слева/центр/справа)
5. **Особенности** (галочки):
   - [ ] Ниша — сколько и размеры
   - [ ] Закругление / кривой угол
   - [ ] Разная по высоте (низ/центр/верх)
   - [ ] Скрытые коммуникации

**Шаг 4. Проёмы (окна, двери)**
- На какой стене? (выбор)
- Ширина, высота
- Глубина откоса (если есть)

**Шаг 5. Коммуникации**
- Вода, газ, электрика, канализация, вентиляция
- На какой стене, на какой высоте

**Шаг 6. Мебель / техника**
- Что планируется?
- Габариты (длина × ширина × высота)
- Требования (вода/слив/свет)

**Шаг 7. Проверка**
- Бо показывает контур комнаты (сумма стен)
- Если расхождение > 5% — переспросить

**Шаг 8. Итог**
- Карточка комнаты со всеми данными
- Кнопки: "К размерам" / "В 3D" / "Проверить мебель"

## Чек-лист перед выездом

### Инструменты
- [ ] Рулетка 5-10 м (проверить — не растянута)
- [ ] Лазерный дальномер (заряжен, калиброван)
- [ ] Уровень (пузырьковый)
- [ ] Отвес
- [ ] Угольник
- [ ] Блокнот / планшет
- [ ] Карандаш / ручка

### Техника
- [ ] Телефон заряжен > 80%
- [ ] Бот Бо открыт
- [ ] Интернет есть
- [ ] Powerbank (на длинный замер)

### Подготовка
- [ ] Адрес, контакт заказчика
- [ ] Доступ в помещение (ключи, код)
- [ ] Согласовано время
- [ ] Уточнено: черновая / чистовая

### Перед замером
- [ ] Осмотреть комнату — понять форму
- [ ] Найти дверь — от неё обход
- [ ] Проверить лазер (см. «Проверка лазера»)
- [ ] Встать в дверном проёме, лицом в комнату
