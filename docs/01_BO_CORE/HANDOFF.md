# 🤝 HANDOFF — Протокол передачи проекта (Ядро Бо)

> **Для кого:** Для нового ИИ-ассистента или разработчика.
> **Цель:** Быстро войти в курс дела и начать работу без ошибок.

## 1. ПРАВИЛО RAW-ССЫЛОК (ГЛАВНОЕ)

**Никогда не проси пользователя копировать большие тексты в чат.**
Если тебе нужен код или документ, который не открывается через веб-поиск, **ты обязан запросить прямую Raw-ссылку (raw.githubusercontent.com)**, чтобы пользователь просто скопировал её одним нажатием.

*Пример правильного запроса:*
> «Пришли мне, пожалуйста, Raw-ссылку на файл core/geometry.py, чтобы я изучил математику расчетов».

## 2. ЧТО ПРОЧИТАТЬ ПЕРВЫМ ДЕЛОМ

Прежде чем писать код или предлагать изменения, прочитай эти документы по порядку:
1. documenty/01_BO_CORE/RULES.md — Строгие правила работы (STRICT MODE).
2. documenty/01_BO_CORE/MANIFEST.md — Философия и суть проекта.
3. documenty/01_BO_CORE/ARCHITECTURE.md — Как устроено ядро.
4. documenty/01_BO_CORE/STATE.md — Где мы находимся сейчас (текущие баги и планы).

## 3. КАК ОБНОВИТЬ КАРТУ КОДА

Перед любой задачей по поиску обработчиков (callback-ов) или роутеров, обнови авто-карту:
python3 tools/map_scan.py > docs/CODE_MAP_AUTO.md
(Карта покажет, где формируется кнопка и где она обрабатывается).

## 4. ОКРУЖЕНИЕ И КОМАНДЫ

- **Язык:** Python 3.13.
- **База данных:** SQLite (bo72.db).
- **Запуск:** Только через виртуальное окружение! Системный python3 выдаст ошибку ModuleNotFoundError: reportlab.
  venv/bin/python3 bot.py
- **Перезапуск бота:**
  pkill -9 -f "python bot.py" ; sleep 2 ; ./start_all.sh
- **Логи:**
  tail -30 bot_start.log

## 5. ПРАВИЛА БЕЗОПАСНОСТИ (КРАТКО)

1. **Никаких слепых перезаписей.** Только точечные правки.
2. **Всегда бэкап перед рискованным патчем:** cp file file.bak_$(date +%Y%m%d_%H%M%S).
3. **Проверка синтаксиса:** После любой правки запускай python3 -m py_compile <file.py>.
4. **Голые return:** В обработчиках всегда используй return True.
5. **Плавающие номера строк:** Перед sed всегда делай свежий grep -n.

## 6. ГЛАВНЫЕ ГРАБЛИ (ПОДРОБНО В RULES.MD)

- sed -i на Android (busybox) ломает кириллицу. Для русских строк используй python3.
- Локальные импорты внутри функций при выносе кода вызывают NameError. Нужна AST-проверка.
- Дубли роутеров (try_handle) приводят к двойному срабатыванию. Проверяй через grep "_try_".

## 7. АРХИТЕКТУРНЫЕ ПРИНЦИПЫ

- **Ядро независимо:** В папке core/ запрещено импортировать telegram или fastapi.
- **Справочники:** Все тексты и коэффициенты берутся из core/spec.py.
- **God Objects:** Большие файлы (например, rooms.py на 7638 строк) постепенно режутся на модули (см. STATE.md).
