# Переходы между стенами — как это решается

## Что делают в учебных заведениях (обмерная практика)
- Обмеры = «кроки» (черновой набросок от руки)
- Записывают размеры прямо на рисунке
- Помечают проблемные места словами: «кривой угол», «подгонка по месту»
- Фотофиксация с линейкой в кадре
- Не учат «замерить точно» — учат «зафиксировать и передать мастеру»

## Что делают мастера (мебельщики, столяры)
- Метод «шаблон» (картон/бумага) — обминают по контуру
- Метод «tick stick» (рейка с насечками)
- Метод «scribing» — заготовка + циркуль + подгонка на месте

## Вывод для Бо
1. Не заставлять замерщика вычислять углы
2. Спрашивать тип перехода: прямой/непрямой/закругление/кривая
3. Если «кривая» — ставить флаг «подгонка по месту»
4. Выдавать мастеру рекомендацию «сделай шаблон»
5. Фотофиксация обязательна

## Что в БД
- ADD COLUMN needs_onsite_fitting INTEGER
- ADD COLUMN fitting_note TEXT
- Флаг «подгонка по месту» на переходах
