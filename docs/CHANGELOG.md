
## v3.13 — v3.23 (04.10.2026)

### Добавлено — ЭОМ (Электрооборудование и освещение)
- **`core/elec.py`** (521 строка) — группы, автоматы, кабели, фазы L1/L2/L3, балансировка
- **`core/floors.py`** (109 строк) — Помещения (этажи / зоны объекта)
- **`core/visualize.py`** — рендер плана комнаты в PNG (PIL, без ezdxf/reportlab)
- **`core/export/json_export.py`** — JSON-экспорт
- **`core/export/csv_export.py`** — CSV-экспорт (открывается в Excel)
- **Справочники в `spec.py`:** 9 типов групп, 9 кабелей, 15 кухонных позиций, 4 IP-класса, автоматы B/C/D, силовые розетки CEE

### Миграции
- **034** — таблицы `elec_supply`, `elec_groups`, `elec_cables` + `room_comms.group_id`
- **035** — `elec_groups.floor_id`, `phase_l1/l2/l3`
- **036** — привязка групп к этажу

### UI
- **Помещения** — кнопка в карточке объекта, создание, карточка, комнаты
- **ЭОМ объекта** — питание (1ф/3ф), вводной автомат, счётчик, группы
- **ЭОМ этажа** — список групп этажа, создание группы (назначение → фаза → мощность → автовыбор автомата и кабеля)
- **Экспорт** — DXF / JSON / CSV / PNG
- **Отчёты** — 7 листов (Обмерный, Электрика, Сантехника, Плитка, Покраска, Ведомость, PDF)
- **3D-план комнаты** — рендер PNG

### Исправлено
- Pattern в `bot.py` — добавлены `floor_`, `group_`
- Роутер `handle_rooms_callback` — порядок проверок (`obj_floor_` в исключении общего `obj_`)
- `waiting_for` список в `commands.py` — добавлены `floor_new_name`, `group_load_watt`
- Нормализация координат в `calc_wall_coords` (всё в положительной зоне)

### Архитектура (важно)
- **Иерархия:** Объект → Помещение (этаж/зона) → Комната → Точки
- **Группа ЭОМ = на этаже** (`elec_groups.floor_id`), а не в комнате
- **Группа ↔ Комната — через точки** (`room_comms.group_id`)
- **Одна группа = один автомат**, обслуживает N точек в разных комнатах

  - Вводной автомат: `set_input_breaker`, `get_input_breaker`, `format_input_breaker`
  - Компоненты: `add_component`, `get_components`, `delete_component`, `clear_auto_components`, `format_component`
  - **Автокомплектация:** `autocomplete_panel`, `recalc_panel`, `format_panel_components`, `get_panel_stats`
  - **Селективность:** `check_selectivity`, `format_selectivity`
  - **Иерархия:** `add_child_panel`, `set_panel_link_breaker`, `get_children_tree`, `_get_link`

### UI
- **Карточка щита:** кнопки 🔌 Вводной / 🪄 Автокомплектация / 📋 Комплектация / 📊 Статистика
- **Вводной автомат:** выбор типа (Авто/УЗО/Диф/Рубильник) + номинал
- **Дочерние щиты:** кнопка «⬇️ Дочерние щиты (N)» + добавление
- **Создание щита:** `panel_add_type_` (vru/floor/apartment/outdoor)
- **Создание дочернего:** `panel_child_type_` (floor/apartment/subpanel/outdoor)

### Правила
- `min_rating_by_purpose` — минимальные номиналы (розетки 16А, свет 6А и т.д.)
- `max_breaker_1p` = 63А — ограничение 1ф
- `selectivity_factor` = 1.6
- `cos_phi` = 0.9, `safety_factor` = 1.2, `simultaneity_factor` = 0.8

### Исправлено
- Паттерн `bot.py` — добавлены `panels_`, `panel_` (иначе кнопки не нажимались)
- `~/.netrc` — автопересоздание при push
- `input_breaker` — пишется и в компоненты, и в поля щита (для селективности)

### Известные проблемы
- Триггеры пересчёта — не автоматические (только по кнопке)
