# 🗺 UI_MAP — Карта интерфейсов Telegram-бота

> **Версия:** 2.0
> **Дата:** 2026-10-25
> **Проект:** Бо 8.1 (Telegram-интерфейс)

> Единый источник правды для кнопок в Telegram.
> **Правило:** Новая кнопка -> сначала в этот файл -> потом код.

## 1. Главный экран (Main Menu)
В боте: handlers/commands/keyboards.py (main_menu_keyboard).

| № | Текст кнопки | Действие (callback_data) | Куда ведет |
|---|---|---|---|
| 1 | 🏗 Объекты | menu_objects | Экран Список объектов |
| 2 | 📋 Задачи | menu_tasks | Экран Все задачи |
| 3 | 💰 Финансы | menu_finance | Экран Финансы |
| 4 | 📊 Сметы | menu_estimates | Экран Сметы |
| 5 | 📈 Отчёты | menu_reports | Экран Отчёты |
| 6 | 📊 KPI | menu_kpi | Экран KPI |
| 7 | 💸 Личные | menu_personal | Экран Личные расходы |
| 8 | 👥 CRM | menu_crm | Экран CRM |
| 9 | 🌐 Дашборд | menu_dashboard | Экран Дашборд |
| 10| ➕ Добавить | menu_add | Модалка добавления |
| 11| ⚙️ Помощь | menu_help | Экран Помощь |

---

## 2. Список объектов (Objects List)
Открывается из Главного экрана.

| № | Элемент | Действие | Куда ведет |
|---|---|---|---|
| 1 | Карточка объекта (название, статус) | obj_card_{id} | Экран Объект |
| 2 | 📦 Архив объектов | obj_archive_list | Экран Архив |
| 3 | ⬅️ Назад | menu_main | Главный экран |
