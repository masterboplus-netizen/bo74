# 🎨 STYLE_GUIDE.md — Правила оформления UI Бо

> Версия: 1.0
> Дата: 2026-10-05
> Статус: Обязательно к исполнению

## 1. ЗАГОЛОВКИ

- Эмодзи один в начале
- Без `*...*`, `**...**`, `_..._`
- Название в «...»
- Пустая строка после

✅ Правильно: 📋 Группы щита «Щит этажа»
❌ Неправильно: ⚡ *Группы щита «Щит этажа»*

## 2. СПИСКИ

- Нумерация 1., 2., 3. (если однотипные)
- Название с эмодзи
- Параметры с отступом 3 пробела
- Разделитель ` · `

✅ Правильно:
1. 💡 Освещение 500Вт
   1ф · 500 Вт · 1P C6
   Кабель: 3x1.5

## 3. МЕТРИКИ

- Один эмодзи в начале
- Разделитель ` · `

✅ Правильно: 📊 Групп: 6 · Σ 21 000 Вт

## 4. КНОПКИ

- Эмодзи + пробел + текст
- Без разметки
- Нумерация если много (1., 2.)
- Максимум 40 символов

✅ Правильно: [1. 💡 Освещение 500Вт]
❌ Неправильно: [Автомат 1P 6А C] (5 таких без номеров)

## 5. ЭМОДЗИ ПО ТИПАМ

| Раздел | Эмодзи |
|--------|--------|
| Щиты | ⚡ |
| Группы | 💡 🔌 🍳 🚨 💨 ❄️ 🔥 📦 |
| Трассы | 📏 |
| Сметы | 💰 |
| Компоненты | 🔌 🛡 ⚙️ 📊 📏 🔗 |
| Навигация | ⬅️ ➡️ 🔄 ➕ 🗑 ✏️ |
| Объекты | 🏗️ |
| Помещения | 🏠 |
| Комнаты | 📦 |
| Коммуникации | 🔧 |
| Задачи | 📋 |
| Фото | 📸 |

## 6. ЗАПРЕЩЕНО

- `*жирный*`, `_курсив_`, `**двойной**`
- Дубли эмодзи (🍳 🍳)
- Двойные пробелы, лишние переносы

## 7. ДЛИНА

- Максимум 4000 символов
- Обрезать с `... (обрезано)`

## 8. ЭМОДЗИ В БД

- В БД (имя группы) — БЕЗ эмодзи
- В UI — добавляется по purpose

## 9. ЭТАЛОН — Экран групп щита

📋 Группы щита «Щит этажа»

1. 💡 Освещение 500Вт
   1ф · 500 Вт · 1P C6
   Кабель: 3x1.5
2. 🔌 Розеточная группа 500Вт
   1ф · 500 Вт · 1P C6
   Кабель: 3x1.5

📊 Групп: 6 · Σ 21 000 Вт

## 10. ЧЕК-ЛИСТ ПЕРЕД КОММИТОМ

- [ ] Заголовки без звёздочек
- [ ] Списки пронумерованы
- [ ] Эмодзи не дублируется
- [ ] Навигация внизу
- [ ] < 4000 символов
